# CryoSat-2 Performance Monitoring portal (csqa)

Public web portal showing the CryoSat-2 performance monitoring (QCV) results: maps and
statistics of monitored L2 / L2i parameters for each 30-day data take (cycle) and product
baseline, plus statistics trends.

The content is generated by the CSQA QCV processing tools in the CPOM v2 python repository
(`cpom_software2/src/cpom/altimetry/projects/csqa`), which write to a data directory outside the
web root (default `/raid6/www/csqa_data`).

## Structure

| File | Purpose |
|------|---------|
| `config.php` | data directory (`CSQA_DATA_DIR`), contact, CDN library URLs |
| `index.php` | overview: latest cycles per baseline, monitored parameters |
| `parameter.php` | a parameter's maps, cycle statistics, trends and all-cycles table |
| `cycles.php` | list of data takes (cycles) with input coverage per baseline, date finder |
| `about.php` | documentation |
| `plot.php` | serves plot images from the data directory (validated query parameters) |
| `download.php` | download of a parameter's statistics timeseries (CSV) |
| `includes/` | shared page header/menu, footer and data access functions |
| `assets/` | CSS, JavaScript (trend charts, map viewer) and images |

Parameters, areas, modes and cycles are not configured here: the portal reads them from
`<data dir>/manifest.json`, written by the processing tools. Adding a parameter to
`csqa_parameters.yaml` and processing it makes it appear in the portal menu.

Libraries (from CDNs): Bootstrap 5.3, Font Awesome 6, Plotly 2.

## Requirements

- PHP 8.x (no extensions beyond the defaults)
- read access for the web server user to the data directory

## Local development

```bash
php -S 127.0.0.1:8124 -t ~/Sites/csqa
```

and open http://127.0.0.1:8124. To use a different data directory:

```bash
CSQA_DATA_DIR=/path/to/csqa_data php -S 127.0.0.1:8124 -t ~/Sites/csqa
```

## Production (Apache)

Deploy with `git pull` into the web directory. Example Apache configuration:

```apache
Alias /qa2 /var/www/csqa
<Directory /var/www/csqa>
    Require all granted
    # optional: override the data directory set in config.php
    SetEnv CSQA_DATA_DIR /raid6/www/csqa_data
</Directory>
```

## Updating the content

On the production server (from `cpom_software2/src/cpom/altimetry/projects/csqa`):

```bash
# routine update, ie daily from cron: reprocess the latest cycles whose input files changed
python process_cycles.py --latest 3 --update --workers 3

# full mission (re)processing
python process_cycles.py --all --workers 8
```
